# アクティカウンター

アクティメソッド（`acti-island.com/typing`）のタイピング結果を日次でカウントし、手動ストップウォッチの履歴も保存する Manifest V3 Chrome 拡張機能です。

## 開発版として読み込む

1. Chrome で `chrome://extensions` を開く。
2. 「デベロッパーモード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を選択する。
4. このリポジトリのルートディレクトリを選択する。

対象サイトの `/typing` を開くと、右上にカウンターとストップウォッチが表示されます。パネルはヘッダーをドラッグして移動でき、位置は Chrome の再起動後も保持されます。歯車ボタンの設定・履歴画面では、目標回数の変更と過去90日の記録確認ができます。

## 仕様・実装方針

詳細は [docs/implementation-guide.md](docs/implementation-guide.md) を参照してください。

- 対象はデスクトップ版 Chrome のみ。
- データは拡張機能のローカルストレージへ保存し、外部送信しない。
- タイピング回数は「今回のタイピング結果」の表示を検知して加算する。
- ストップウォッチは対象タブ間で共有し、停止時に履歴へ保存する。
